# Assets

Place these PNGs here before building:

- `icon.png` — 1024×1024 app icon (no transparency, no rounded corners — Apple/Google add them)
- `splash.png` — 1242×2436 (iPhone Pro Max-ish), centered logo on the dark bg

Until you add real ones, run with `expo start` — Expo provides defaults in dev. Production builds will fail without these files.
